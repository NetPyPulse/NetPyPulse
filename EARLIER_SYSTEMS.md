# Earlier automation systems

## Helios

**Python · asyncio · WebSockets · Patchright · aiogram · SQLite**

Helios contains session configuration and lifecycle code, strategy persistence, withdrawal analytics, latency tracking, event fanout, and Telegram integration. It shows the earlier development of the account orchestration and operations patterns that recur in the later projects.

Its dependency list also includes NumPy, optional scikit-learn, orjson, and Linux uvloop. A dependency declaration alone does not establish machine-learning expertise, so these libraries are not presented as a separate specialization.

## Spectre

**Python · browser automation · Telegram control**

Spectre is an earlier multi-account gaming automation project with remote status, session controls, balance checks, log access, withdrawal workflows, and configurable execution behavior. It provides context for the move toward clearer service boundaries and durable state in Talon.

The older README contains strong latency, uptime, and reliability claims. This portfolio omits those claims because independent measurement evidence was not established during the portfolio review.

## Additional MT5 experiments

The local project collection includes Python MT5 strategy scripts for scalping and retest experiments. They are exploratory work. Aegis Meridian is the stronger public case study because it has a defined architecture, reproducible validation, and explicit execution boundaries.

## The progression

```text
Session automation and operator controls
                 ↓
Measured Python runtime and recovery work
                 ↓
Separated Rust event processing and Python orchestration
                 ↓
Durable state, explicit execution outcomes, and reproducible validation
```

VolaPilot develops the product-interface side of this work; Aegis Meridian develops the research and broker-execution side.
